# ИИ-прокси на Cloudflare Workers

Приложение не может обращаться к Gemini напрямую: веб-бандл публичен, и ключ,
вшитый в него, — это ключ, отданный всем желающим. Счёт при этом придёт вам.

Поэтому ключ живёт здесь, в Worker'е, как секрет и наружу не выходит.

## Почему бесплатно

| Сервис | Бесплатный лимит |
|---|---|
| Cloudflare Workers | 100 000 запросов в сутки |
| Gemini Developer API | собственная бесплатная квота |

Карта не нужна ни там, ни там. Firebase Functions для этой же задачи потребовал
бы перехода на тариф Blaze с привязкой карты — поэтому выбран Cloudflare.

## Установка

**1. Получите ключ Gemini** на https://aistudio.google.com/apikey — вход
обычным Google-аккаунтом, ключ выдаётся сразу.

**2. Разверните Worker:**

```bash
cd worker
npx wrangler login          # откроется браузер
npx wrangler secret put GEMINI_API_KEY   # вставьте ключ, он не попадёт в git
npx wrangler deploy
```

Wrangler напечатает адрес вида `https://child-health-ai.NAME.workers.dev`.

**3. Пересоберите приложение с этим адресом:**

```bash
cd ..
flutter build web --release --dart-define=AI_PROXY_URL=https://child-health-ai.NAME.workers.dev
firebase deploy --only hosting
```

Без `AI_PROXY_URL` помощник просто отключён: база знаний и проверка тревожных
признаков продолжают работать, а на экране чата появляется объяснение, как его
включить. Ошибок в рантайме не будет.

## Безопасность

- `ALLOWED_ORIGIN` в `wrangler.toml` ограничивает CORS доменом приложения.
  Пока стоит `*`, вашу квоту может тратить чужая страница.
- Длина запроса ограничена, чтобы один вызов не выжег суточную квоту.
- Текст ошибки от Gemini наружу не пересылается: он может содержать ключ.
- Ответ, заблокированный фильтрами безопасности, превращается в понятное
  сообщение, а не в пустой пузырь.

## Что Worker намеренно НЕ делает

Он не принимает решений о срочности. Проверка тревожных признаков выполняется
в приложении **до** обращения к модели: если в вопросе есть красный флаг,
запрос сюда вообще не уходит — см. `lib/ai/assistant_service.dart` и
`lib/knowledge/triage.dart`.
